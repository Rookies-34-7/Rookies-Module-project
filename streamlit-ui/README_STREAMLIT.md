# 자니(Zzz-ni) 수면 건강 분석

생활 습관과 수면 정보를 입력하면 수면 상태를 분석하고, 결과 그래프와 개인 맞춤 팁을 제공하는 Streamlit 웹 애플리케이션입니다.

## 주요 기능

- 간단 측정과 상세 측정 입력 폼
- 취침·기상 시각을 이용한 하루 수면시간 자동 계산
- 키와 몸무게를 이용한 BMI 자동 계산
- 불면증·수면무호흡증·수면 부족 위험도 그래프
- 수면 건강 점수 게이지와 상태 표시
- 입력한 상세 데이터 확인
- 무작위 개인 맞춤 수면 관리 팁
- OpenAI API 기반 AI 수면 코치
- 야간 도시 배경과 반복 재생 배경음악

## 입력 항목

### 간단 측정

- 나이, 성별
- 키, 몸무게
- 취침시간, 기상시간
- 신체 활동 수준(분/일)
- 스트레스 지수(1~10)

### 상세 측정

간단 측정 항목에 다음 정보가 추가됩니다.

- 혈압(수축기/이완기)
- 안정 시 심박수(회/분)
- 하루 걸음 수
- 하루 카페인 섭취량(잔)
- 하루 휴대폰 사용시간
- 흡연 여부
- 최근 24시간 내 음주 여부
- 낮 시간 졸림 정도(1~10)

## 실행 방법

PowerShell에서 프로젝트 폴더로 이동한 후 실행합니다.

```powershell
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

실행 후 브라우저에서 `http://localhost:8501`을 열면 됩니다.

`streamlit` 명령을 찾을 수 없다는 메시지가 나오면 `streamlit run` 대신 위와 같이 `python -m streamlit run`을 사용합니다.

## AI 수면 코치 설정

프로젝트 최상위 폴더에 `.env` 파일을 만들고 본인의 API 키를 입력합니다.

```dotenv
OPENAI_API_KEY=본인의_API_키
OPENAI_MODEL=gpt-4.1-mini
```

- `.env`는 GitHub에 업로드하거나 다른 사람과 공유하지 않습니다.
- 저장소의 `.gitignore`에 `.env`가 포함되어 있는지 커밋 전에 확인합니다.
- API 키가 없어도 입력 폼과 결과 화면은 사용할 수 있지만 AI 수면 코치 답변은 생성되지 않습니다.

## 입력값 검증 기준

- 키: 120~220cm
- 몸무게: 30~200kg
- 나이: 18~100세
- 스트레스 및 낮 시간 졸림: 1~10
- 상세 폼의 안정 시 심박수 입력 범위: 40~140회/분

일반 성인의 안정 시 심박수는 보통 60~100회/분이며, 입력 가능 범위와 상태 판정 기준은 구분해서 관리해야 합니다.

## 파일 구성

| 파일 또는 폴더 | 역할 |
| --- | --- |
| `streamlit_app.py` | 입력 폼, 결과 분석, 그래프 및 챗봇 로직 |
| `style.css` | 야간 도시 배경과 전체 UI 스타일 |
| `assets/` | 배경 이미지와 배경음악 파일 |
| `.streamlit/config.toml` | Streamlit 테마 및 서버 설정 |
| `requirements.txt` | 실행에 필요한 Python 패키지 목록 |
| `README_STREAMLIT.md` | 실행 및 기능 안내 문서 |

## 사용 패키지

- Plotly
- OpenAI Python SDK
- python-dotenv

## 참고 사항

- CSS만 수정했을 때 화면에 바로 반영되지 않으면 브라우저를 새로고침하거나 `R` 키를 누릅니다.
- 배경음악 자동 재생은 브라우저 정책에 따라 첫 클릭 이후 시작될 수 있습니다.
- 결과는 건강 관리 참고용이며, 증상이 지속되거나 심하면 의료진과 상담해야 합니다.
